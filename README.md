# Akshay G Portfolio

A modern, responsive portfolio website showcasing my work as a Full Stack Developer.

## 🌐 Live Demo

Visit my portfolio: [akshayg-portfolio.netlify.app](https://akshayg-portfolio.netlify.app)

## ✨ Features

- Responsive design that works on all devices
- Modern animations and transitions
- Dark theme
- Portfolio project showcase
- Skills section with progress bars
- Contact form integration
- Smooth scrolling
- Loading animations
- Project filtering

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Box Icons
- MixItUp for filtering

## 🚀 Setup

1. Clone the repository:
```bash
git clone https://github.com/Akshay0922/My-Portfolio.git
```

2. Navigate to the project:
```bash
cd My-Portfolio
```

3. Open `index.html` in your browser or use a live server.
